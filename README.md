## 🚀 How to Enable GitHub Pages (One-Time Setup)

If GitHub Pages is not yet active on the repository:
1. Go to repository **Settings** on GitHub: `https://github.com/Virajnaik31/DD_v4.6.4_Report/settings/pages`
2. Under **Build and deployment** > **Source**, select:
   - **Deploy from a branch**
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, your live site will be live at:
   👉 **`https://virajnaik31.github.io/DD_v4.6.4_Report/`**
